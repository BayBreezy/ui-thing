So you want to use UI Thing in your Nuxt project? Great! This guide will walk you through the steps to get started.

## Prerequisites

Before you can use UI Thing, you need to have a Nuxt project. If you don't have one yet, you can create one with the following command:

:prose-pm-x{command="nuxi@latest init my-app"}

This will create a new Nuxt project in the `my-app` directory. You can then navigate to that directory and start the development server:

```bash
cd my-app && npm run dev
```

UI Thing works with both Nuxt 3 and Nuxt 4. The CLI detects which one you are using and picks matching default folders (`app/components/Ui` for Nuxt 4, `components/Ui` for Nuxt 3).

## Initialization

Once you have a Nuxt project, you can initialize UI Thing with the following command:

:prose-pm-x{command="ui-thing@latest init"}

This command will ask you a bunch of question the first time you run it

```bash
✔ Which theme do you want to start with? › Violet
✔ Where is your tailwind.css file located? … app/assets/css/tailwind.css
✔ Where should your components be stored? … app/components/Ui
✔ Where should your composables be stored? … app/composables
✔ Where should your plugins be stored? … app/plugins
✔ Where should your utils be stored? … app/utils
✔ Should we just replace component files if they already exist? … yes
✔ Would you like to use the default filename when adding components? … yes
✔ Which package manager do you use? › Npm
```

Your answers are saved in a `ui-thing.config.ts` file at the root of your project, so you are only asked once. Package manager choices are Npm, Yarn, Pnpm, Bun and Deno.

Want to skip the questions? Run `ui-thing@latest init --yes` to accept the defaults (Zinc theme and the standard folders). It detects your package manager from your lockfile and skips the Prettier question; run `ui-thing@latest prettier` later if you want it.

**UI Thing** will then:

- Install the core dependencies (Tailwind CSS v4 with its Vite plugin, Reka UI, `tailwind-variants`, `tailwind-merge`, `motion-v`, and a few Nuxt modules) and TypeScript 6 (TypeScript 7 is not supported by Vue's compiler yet)
- Update your `nuxt.config` with the required modules, color mode and icon settings, `tv` and `VariantProps` auto-imports, and your Tailwind CSS file
- Write your Tailwind CSS file with the theme you picked
- Add a `tw-helper.ts` util for Tailwind class autocomplete
- Merge recommended settings into your `.vscode` folder
- Ask if you want an opinionated Prettier config

Check your setup at any time with:

:prose-pm-x{command="ui-thing@latest info"}

It shows your Nuxt, TypeScript and Tailwind versions, the folders UI Thing uses, the components you have installed, and warnings for anything that will cause problems.

## Adding components

Once initialized, add components by running:

:prose-pm-x{command="ui-thing@latest add"}

You'll be prompted to select the components you want. Already know what you need? Pass the names directly:

:prose-pm-x{command="ui-thing@latest add button card dialog"}

**UI Thing** will then:

- Copy the selected components into your components directory
- Add any required composables, utils, and plugins
- Add any Nuxt modules a component needs to your `nuxt.config`
- Ask to install the dependencies a component needs

Because the files are copied into your project, they are yours to edit.

Want to look before you add? `ui-thing@latest view button` prints a component's source and what it depends on, and `ui-thing@latest add button card --dry-run` lists the files, packages and Nuxt modules `add` would change, without writing anything.

### Components from other registries

`add` also installs components from any shadcn-style registry, such as [Vue Bits](https://vue-bits.dev) or [NXUI](https://nxui.geoql.in), so you don't have to port them by hand:

:prose-pm-x{command="ui-thing@latest add @vue-bits/HoloMosaic"}

You can also pass the URL of a registry item. See the [CLI page](/getting-started/cli#registries) for everything the registry support can do.

## Adding blocks

Blocks are ready-made page sections (heroes, pricing tables, dashboards, sign-in screens, settings pages and more) built from UI Thing components. Browse them in the [blocks docs](/blocks/hero) or from the CLI:

:prose-pm-x{command="ui-thing@latest block"}

Pick a category and the blocks you want, or pass their names:

:prose-pm-x{command="ui-thing@latest block BlockHero1 BlockPricing2"}

The CLI writes each block to `app/components/Blocks`, adds the components it uses, installs the packages it imports, and prints the tag to use, such as `<BlocksHeroBlockHero1 />`.

## Adding themes

UI Thing ships with several pre-made themes.

Add one to your project with:

:prose-pm-x{command="ui-thing@latest theme"}

This will ask you to select the theme you want to add to your project. Already know which one you want? Pass its name, for example `ui-thing@latest theme rose` (add `--yes` to skip the overwrite question).

Once you have selected a theme, UI Thing will ask you if you want to overwrite your `tailwind.css` file. If you answer yes, it will overwrite your `tailwind.css` file with the theme you selected. If you answer no, nothing changes.

⚠️ Please note that this will overwrite your `tailwind.css` file. If you have made any changes to this file, you will lose them.

### Theme source

The themes included in this cli all come from [shadcn/ui theme page](https://ui.shadcn.com/themes).

So if you don't want to use this CLI to add themes, you can just customize your theme on that page and copy the code into your `tailwind.css` file.

> Thanks shadcn for making these themes available for free! 🙏

## Keeping components up to date

When UI Thing ships a fix, see how your copies differ from the latest version before you update:

:prose-pm-x{command="ui-thing@latest diff"}

`ui-thing@latest update button --dry-run` lists the files an update would overwrite. `update` replaces files without merging, so commit your changes first and re-apply your edits from the diff.

## Using UI Thing with AI

UI Thing is built to work well with AI coding agents:

- **Agent skill.** Teaches agents how to plan and build Nuxt apps with UI Thing. Install it with `npx skills add https://github.com/BayBreezy/ui-thing --skill uithing`.
- **MCP server.** Gives your editor the exact source, docs and install plans for every component and block. Connect it with `ui-thing mcp init` (see below).
- **No prompts.** Every CLI command has a non-interactive form (`init --yes`, `add button --yes`, `block BlockHero1 --yes`, `theme rose --yes`), and read-only commands print JSON with `--json`, starting with `ui-thing info --json`.

Connect your editor to the MCP server (`--client` can be `claude`, `cursor` or `vscode`; leave it out to pick from a list):

:prose-pm-x{command="ui-thing@latest mcp init --client claude"}

See the [MCP page](/getting-started/mcp) and the [CLI page](/getting-started/cli) for the details.
