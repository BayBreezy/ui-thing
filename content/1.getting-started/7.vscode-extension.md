title: VS Code Extension
description: Browse, add, compare and update UI Thing components and blocks from a sidebar in VS Code, Cursor or Windsurf.
---

The UI Thing extension puts the CLI in your editor. It adds a sidebar where you can browse and add components and blocks, install items from registries such as Vue Bits and NXUI, and compare your copies with the latest version in the diff editor. It also gives Copilot the UI Thing [MCP server](/getting-started/mcp).

The extension runs the `ui-thing` CLI for you, in a **UI Thing** terminal where you can watch it and answer any questions.

## Install

The extension is installed from a `.vsix` file on GitHub.

1. Download `ui-thing-vscode-extension-<version>.vsix` from the [latest release](https://github.com/BayBreezy/ui-thing-vscode-extension/releases/latest).
2. In VS Code, open the **Extensions** view, click the `···` menu at the top and choose **Install from VSIX…**, then pick the file.

Or install it from a terminal:

```bash
code --install-extension ui-thing-vscode-extension-0.1.0.vsix
```

Cursor and Windsurf work the same way. Use `cursor --install-extension` or `windsurf --install-extension` instead of `code`.

::prose-callout{variant="info" title="Updates"}
Extensions installed from a `.vsix` file do not update themselves. Check the [releases page](https://github.com/BayBreezy/ui-thing-vscode-extension/releases) for new versions, and install a new one the same way. It replaces the old one.
::

## Getting started

1. Open a Nuxt project, or run **UI Thing: Create Nuxt Project** from the Command Palette.
2. Click the UI Thing icon in the Activity Bar, then **Initialize UI Thing**.
3. Add components from the **Components** view, and page sections from **Blocks**.

## The sidebar

- **Installed**: the components and registry items in your project. Hover an item to open its docs, compare it with the latest version, update it or remove it. Click it to open the file.
- **Components**: the whole catalog, with installed components marked. Click one to read its source, or add it with the `+` button.
- **Blocks**: ready-made page sections by category (heroes, pricing, dashboards, sign-in pages and more).

Select several items to add, update or remove them together.

## Commands

Open the Command Palette and type **UI Thing** to see every command. Each one runs the matching [CLI command](/getting-started/cli).

| Command                       | Runs                              |
| ----------------------------- | --------------------------------- |
| Initialize                    | `ui-thing init`                   |
| Project Info                  | `ui-thing info`                   |
| Add Components                | `ui-thing add`                    |
| Add Blocks                    | `ui-thing block`                  |
| Add from Registry             | `ui-thing add @namespace/name`    |
| Add Registry Namespace        | `ui-thing registry add-namespace` |
| Compare with Latest Version   | opens VS Code's diff editor       |
| Update Components             | `ui-thing update`                 |
| Remove Components             | `ui-thing remove`                 |
| Change Theme                  | `ui-thing theme`                  |
| Add Prettier Config           | `ui-thing prettier`               |
| Add Shortcuts Composable      | `ui-thing shortcuts`              |
| Connect MCP Server to Project | `ui-thing mcp init`               |
| Install Agent Skill           | `npx skills add …`                |

## Copilot and the MCP server

In VS Code, the extension registers the UI Thing MCP server for you. Switch Copilot Chat to agent mode and ask it to build a page with UI Thing. It can look up the exact source, docs and install plan for every component and block, with no `mcp.json` to write.

If you already set up the server in `.vscode/mcp.json`, turn this off with the `uithing.mcp.enabled` setting so it isn't listed twice.

## Settings

| Setting                    | Default                   | Description                                                                 |
| -------------------------- | ------------------------- | --------------------------------------------------------------------------- |
| `uithing.packageManager`   | `auto`                    | `auto`, `npm`, `pnpm`, `yarn`, `bun` or `deno`. `auto` reads your lockfile. |
| `uithing.cliChannel`       | `latest`                  | Version of the CLI to run, for example `0.4.1`.                             |
| `uithing.catalog.cacheTTL` | `86400`                   | Seconds to cache the components and blocks catalogs.                        |
| `uithing.mcp.enabled`      | `true`                    | Provide the UI Thing MCP server to VS Code.                                 |
| `uithing.mcp.url`          | `https://uithing.com/mcp` | MCP server URL.                                                             |

## Requirements

- VS Code 1.104 or newer, or a Cursor or Windsurf release based on it. In Cursor and Windsurf, connect the MCP server with **Connect MCP Server to Project** instead.
- Node.js 20 or newer.
- An internet connection to load the components and blocks catalogs. A cached copy is used when you're offline.
