## About

AI Elements are patterns for building agentic interfaces. Each one is a composition of UI Thing components that you copy into your project. There is no package to install. The code is yours.

A [Chat](/ai-elements/chat) is a list of [Message](/ai-elements/message) turns inside a [Message Scroller](/components/message-scroller). The steps an agent takes inside a turn, like [Reasoning](/ai-elements/reasoning), [Tool](/ai-elements/tool) and [Plan](/ai-elements/plan), are built on [Trace](/components/trace), so every step has the same shape. Code, terminal output and diffs are shown with [Code Block](/components/code-block).

::prose-callout{variant="info" title="Patterns, not packages"}
Patterns are not installed with the CLI. Open a pattern, run the command on its page to add the components it uses (for example `ui-thing@latest add trace code-block`), and copy the example into your project.
::

## Using them

1. Add the components the pattern uses:

   ```bash
   npx ui-thing@latest add trace code-block
   ```

2. Open a pattern above and copy its code into your project. Each page lists any other components it needs.

3. Wire it to your data. The examples simulate streaming with VueUse so they run on their own. Swap the simulation for `new Chat()` from `@ai-sdk/vue`, or whatever your backend gives you. The AI SDK sections of each page show how the parts map.

The demos share a tiny Markdown renderer so you can see fenced code render as a [Code Block](/components/code-block). In your app, use the Markdown library you already have and map fenced code to `UiCodeBlock`.

::prose-callout{variant="info" title="Utilities"}
Trace and Code Block use the [shimmer](/utilities/shimmer) and [scroll fade](/utilities/scroll-fade) utilities. Add them to your CSS if you have not yet.
::
