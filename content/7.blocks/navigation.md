Desktop menus are hidden below the `lg` breakpoint, where a sheet menu takes over. Click the `Full Screen View` button ( :icon{name="lucide:gallery-vertical" class="inline"} ) at the top of a preview to see the desktop layout, and resize the preview to see the mobile menu.

None of these headers use remote images. Replace the link arrays with your own routes and swap `NuxtLink` targets for real paths.
