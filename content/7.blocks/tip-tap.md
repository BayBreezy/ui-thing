## Style One

Custom Tiptap instance with grouped icon buttons and tooltips. Features organized button groups for text formatting (bold, italic, strike), headings (H1-H3), lists (bullet, ordered), and block elements (code, blockquote). Includes undo/redo actions with disabled states.

## Style Two

A minimal editor for short posts and status updates. A small bar with bold, italic and link buttons, a placeholder, a character counter that warns near the limit and a post button that stays disabled until there is something to post.

## Style Three

An editor with a bubble menu. There is no toolbar. Select text and a floating menu offers bold, italic, underline, a heading, a quote and a link field.

:BlockShowcase{blockPath="Tiptap/BlockTiptap3" component="BlockTiptap3" iframeHeight="560px"}

## Style Four

A comment and notes editor. A compact card that grows with its content, a small toolbar, a thread of earlier comments and a comment button that is disabled until you type.

:BlockShowcase{blockPath="Tiptap/BlockTiptap4" component="BlockTiptap4" iframeHeight="760px"}

## Style Five

A blog post editor with a large title, a toolbar with a block type select, an edit and preview switch, a word count with reading time and a saved indicator that updates after you stop typing.
