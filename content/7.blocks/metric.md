---
title: Metric
description: Marketing metric sections whose numbers count up when they scroll into view. Panels, strips, cards with charts, progress rings and a quote with stats. Built with theme tokens and no external images.
---

Each block takes a `stats` array with `value`, `label` and optional `prefix`, `suffix` and `decimals`, so `{ value: 99.9, suffix: "%", decimals: 1 }` renders `99.9%`. Values count up once, the first time the section is visible.
